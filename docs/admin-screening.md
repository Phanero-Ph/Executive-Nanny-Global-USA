# Agency screening before matching

Open Admin → Overview & submissions → Caregiver applications → Review.

1. Review the application and its private documents.
2. Complete the identity, employment history and suitability checklist.
3. Contact every listed referee, record verification evidence, and save screening.
4. Verify current CPR, First Aid and background check documents in Credential reviews.
5. Change the application status to Eligible for matching.

Approval and matching require all checks. Existing active applications also need screening before new matching actions. Return an active application to Screening to edit its checklist; resolve existing placements through matching first. Credential validity is checked again for the placement start date.

For corrections, save a screening review, select Changes requested and supply applicant-facing feedback. Applicants see this feedback, can edit and resubmit, and require fresh screening. Application rejected also requires feedback but does not allow applicant editing. Private notes, reference evidence and audit history stay administrator-only.

Request Caregiver opens the paid caregiver request queue. Unconfirmed search-fee requests remain hidden. Agency selection proceeds directly to placement without family-to-candidate interviews. Internal recruiter screening remains available.
